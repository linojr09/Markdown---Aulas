> ## Windows
> 
  ###### Comandos básicos do Windows
  - **dir** (Lista arquivos e pastas do diretório atual)
- **cd** (Muda de diretório)
- **cd..** (Volta para a pasta anterior)
- **cls** (Limpa a tela do CMD)
- **mkdir ou md** (Cria uma nova pasta)
- **rmdir ou rd** (Remove uma pasta vazia)
- **del** (Exclui arquivos)
- **copy** (Copia arquivos)
- **move** (Move arquivos ou pastas)
 
 ###### Atalhos importantes no Windows:
- **Win + E** (Abrir Explorador de Arquivos)
- **Win + R** (Abrir Executar)
- **Win + D** (Mostrar área de trabalho)	
- **Ctrl + Shift + Esc** (Abrir Gerenciador de Tarefas)
- **Win + L** (Bloquear o computador)
- **cmd** (Abre o Prompt de Comando)
- **powershell** (Abre o PowerShell)
- **notepad** (Bloco de Notas)
- **control** (Painel de Controle)
- **msconfig** (Configuração do Sistema)
- **services.msc** (Serviços do Windows)

> ## Malwares

- É qualquer código ou programa desenvolvido intencionalmente para causar danos ao sistema
- Roubar informações
- Espionar o usuário
- Obter acesso não autorizado
-  Lucrar às custas da vítima

> ## Existem 5 tipos

- Ransomware, conhecido como o Sequestrador
- Keylogger, o espião
- Cryptojacker / Minerador
- Backdoor, a porta dos fundos
- Trojan, o disfarçado

 > ##   Diagnóstico de Problemas em Software

 ## Tipos de Problemas de Software

 - Bug Programa trava ou fecha sozinho durante o uso
 -  Configuração Programa não inicia devido a parâmetros incorretos
 -  Dependência Biblioteca ou componente ausente impede a execução
 -  Desempenho CPU ou RAM em uso excessivo, sistema lento
 -  Serviço Serviço do sistema parado ou em falha

 ##  Diagnóstico 

-  Identificar, Observe os sintomas e classifique o tipo de problema
- Investigar, Escolha a ferramenta adequada e colete evidências
- Resolver, Aplique a correção e valide o funcionamento do sistema
